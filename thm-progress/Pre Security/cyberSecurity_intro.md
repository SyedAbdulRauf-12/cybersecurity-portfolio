# Module 1: Intro to Cybersecurity

Cybersecurity is the discipline of protecting networks, devices, software programs, and data from unauthorized digital access, manipulation, disruption, or destruction.

## Offensive Security Intro

Offensive security (often referred to as the Red Team) centers on proactive security testing by simulating real-world malicious attacks against an organization's systems.

- Goal: Discover and exploit vulnerabilities before genuine adversaries do.
- Techniques: Vulnerability assessments, penetration testing, social engineering (e.g., simulated phishing), and physical bypasses.
- Analogy: Hiring an authorized lockpicker to find all weak doors in a bank so management knows which locks to replace.

## Defensive Security Intro

Defensive security (often called the Blue Team) focuses on safeguarding an organization's assets by anticipating, detecting, mitigating, and recovering from attacks.

- Goal: Maintain continuous visibility, build resilient architecture, and respond rapidly when anomalies occur.
- Techniques: Setting up firewalls, patching vulnerabilities, log monitoring via Security Information and Event Management (SIEM) systems, and conducting incident response investigations.
- Analogy: The permanent security guard staff, alarm monitoring station, and building architecture keeping the bank secure 24/7.

## Careers in Cybersecurity

The industry divides into specialized domains based on technical skill sets:

- SOC Analyst (Security Operations Center): Triage alerts, inspect suspicious traffic, and flag active threats.
- Penetration Tester / Ethical Hacker: Probe software and networks for flaws under strict rules of engagement.
- Incident Responder: Forensic specialists who isolate active breaches, eradicate attackers, and assess blast radius.
- Security Engineer / Architect: Design secure infrastructure, identity policies, firewalls, and cryptographic controls.
- Governance, Risk, and Compliance (GRC) Analyst: Ensure organizational policies adhere to external regulations (ISO 27001, GDPR, HIPAA, SOC 2).
